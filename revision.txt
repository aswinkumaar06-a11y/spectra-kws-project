NOISE-POOL PROVENANCE & CHRONOLOGY
================================================================================
Status: Contemporaneous generation with packaging-time string deduplication.
Detailed Record:
1. Generation: noise_pools.json was generated programmatically during execution of split_raw_only.py (prior to augment_per_split.py).
2. Partitioning logic:
   - train: doing_the_dishes.wav, exercise_bike.wav, running_tap.wav, white_noise.wav
   - val: dude_miaowing.wav
   - test: pink_noise.wav (held out / clean test set, no noise augmented into test)
3. Packaging-time operation: Recursive file globbing in split_raw_only.py had matched files both in dataset/raw/noise/ and dataset/raw/noise/_background_noise_/, causing filenames to be listed twice in JSON arrays. At packaging time, duplicate string entries were removed to produce clean unique lists.
4. Model relationship: augment_per_split.py maps filenames to paths using a dictionary lookup (noise_map = {os.path.basename(f): f ...}), meaning duplicate list entries resolved to the identical files. No audio, features, or models were regenerated or altered by this formatting deduplication.
