Splitting is executed by speaker/session group rather than by individual file:

def positive_group_key(path):
    rel = os.path.relpath(path, "dataset/raw/positive")

```python
# Exact excerpt from scripts/split_raw_only.py lines 75-102:
def split_by_group(files, group_fn, train_r=0.70, val_r=0.15, seed=42):
    rng = random.Random(seed)
    groups = {}
    for f in files:
        g = group_fn(f)
        groups.setdefault(g, []).append(f)

    keys = sorted(list(groups.keys()))
    rng.shuffle(keys)
    n = len(keys)
    n_train = max(1, int(train_r * n))
    n_val = max(1, int(val_r * n))

    train_keys = set(keys[:n_train])
    val_keys = set(keys[n_train:n_train + n_val])
    test_keys = set(keys[n_train + n_val:])

    train, val, test = [], [], []
    for k in keys:
        flist = groups[k]
        if k in train_keys:
            train.extend(flist)
        elif k in val_keys:
            val.extend(flist)
        else:
            test.extend(flist)

    return train, val, test, len(keys)
```

### Augmentation Transformations
For each raw training file, five derivative files are written:
1.  `_orig.wav`: Clean, unmodified copy.
2.  `_snr15.wav`: Additive background noise at 15 dB SNR (`rng.choice(noise_files)`).
3.  `_snr5.wav`: Additive background noise at 5 dB SNR.
4.  `_snr0.wav`: Additive background noise at 0 dB SNR.
5.  `_shift.wav`: Time shift via circular roll by `rng.randint(-800, 800)` samples (up to $\pm 50\text{ ms}$).
6.  `_vol.wav`: Volume scale by `rng.uniform(0.5, 0.8)`.

```python
# Exact excerpt from scripts/augment_per_split.py lines 48-53:
def add_noise(clean, noise, snr_db):
    noise = np.resize(noise, clean.shape)
    clean_power = np.mean(clean ** 2)
    noise_power = np.mean(noise ** 2) + 1e-9
    factor = np.sqrt(clean_power / (noise_power * 10 ** (snr_db / 10)))
    return clean + factor * noise
```

### Mathematical Cancellation of Volume Augmentation
Because `audio_utils.normalize_amplitude()` scales audio by $1.0 / \max(|x|)$, any scalar multiplication $x_{\text{scaled}} = c \cdot x$ results in:
$$\frac{c \cdot x}{\max(|c \cdot x|)} = \frac{c \cdot x}{c \cdot \max(|x|)} = \frac{x}{\max(|x|)}$$
**Finding:** Peak normalization in the feature extraction pipeline mathematically neutralizes scalar volume scaling. Consequently, `_vol.wav` derivatives produce MFCC representations bit-for-bit identical to `_orig.wav` derivatives.

### Core Implementations (`scripts/audio_utils.py`)

```python
# Exact excerpt from scripts/audio_utils.py lines 17-51:
def load_and_fix_audio(path_or_audio, sr=SAMPLE_RATE, duration=CLIP_DURATION):
    if isinstance(path_or_audio, str):
        audio, _ = librosa.load(path_or_audio, sr=sr)
    else:
        audio = np.asarray(path_or_audio, dtype=np.float32)

    target_len = int(sr * duration)
    if len(audio) < target_len:
        audio = np.pad(audio, (0, target_len - len(audio)), mode="constant")
    else:
        audio = audio[:target_len]
    return audio.astype(np.float32)

def normalize_amplitude(audio):
    max_amp = np.max(np.abs(audio))
    if max_amp > 1e-6:
        audio = audio / max_amp
    return audio.astype(np.float32)

def check_energy_gate(audio, threshold=ENERGY_GATE_THRESHOLD):
    max_amp = np.max(np.abs(audio))
    return bool(max_amp >= threshold), float(max_amp)
```

```python
# Exact excerpt from scripts/audio_utils.py lines 53-71:
def extract_mfcc(audio, sr=SAMPLE_RATE):
    mfcc = librosa.feature.mfcc(
        y=audio,
        sr=sr,
        n_mfcc=N_MFCC,
        n_fft=N_FFT,
        hop_length=HOP_LENGTH
    )
    if mfcc.shape[1] < N_FRAMES:
        pad_width = N_FRAMES - mfcc.shape[1]
        mfcc = np.pad(mfcc, ((0, 0), (0, pad_width)), mode="constant")
    else:
        mfcc = mfcc[:, :N_FRAMES]
    return mfcc.astype(np.float32)
```

### Route Comparisons & Energy Gate Behavior
1.  **Training Route (`scripts/extract_features.py`):** Fixed to 1.0s, peak-normalized, MFCC extracted. Does **not** apply the energy gate (all training clips are processed).
2.  **File Evaluation Route (`scripts/evaluate_tflite.py`):** Evaluates pre-extracted MFCC features from `X_test.npy`. This constitutes a **classifier-only evaluation**, testing intrinsic discriminability without the energy gate.
3.  **Live Microphone Route (`scripts/test_spectra_model.py`):** Applies `check_energy_gate(clip, threshold=0.03)` on every 1.0s window. If `has_energy` is `False`, feature extraction and model inference are **completely skipped**, outputting a terminal silence status.

def representative_dataset_gen(X_train, y_train=None, num_samples=200, seed=42):
    rng = np.random.default_rng(seed)
    if y_train is not None:
        classes = np.unique(y_train)
        samples_per_class = max(1, num_samples // len(classes))
        chosen_indices = []
        for c in classes:
            c_indices = np.where(y_train == c)[0]
            chosen = rng.choice(c_indices, size=min(samples_per_class, len(c_indices)), replace=False)
            chosen_indices.extend(chosen)
        rng.shuffle(chosen_indices)
    else:
        chosen_indices = rng.choice(len(X_train), size=min(num_samples, len(X_train)), replace=False)

    for idx in chosen_indices:
        yield [X_train[idx:idx+1].astype(np.float32)]

converter = tf.lite.TFLiteConverter.from_keras_model(model)
converter.optimizations = [tf.lite.Optimize.DEFAULT]
converter.representative_dataset = lambda: representative_dataset_gen(X_train, y_train, num_samples=200, seed=42)
converter.target_spec.supported_ops = [tf.lite.OpsSet.TFLITE_BUILTINS_INT8]
converter.inference_input_type = tf.int8
converter.inference_output_type = tf.int8

def quantize_to_int8(x, scale, zero_point):
    q = np.round(x / scale) + zero_point
    return np.clip(q, -128, 127).astype(np.int8)

def dequantize_from_int8(q, scale, zero_point):
    return (q.astype(np.float32) - zero_point) * scale

## 9. Live Buffering and Latency Analysis

### Microphone Callback & Buffer Consumption (`scripts/test_spectra_model.py`)
```python
# Exact excerpt from scripts/test_spectra_model.py lines 120-145:
def callback(indata, frames, time_info, status):
    if status:
        print(f"\nAudio callback status: {status}")
    try:
        audio_q.put_nowait(indata.copy())
    except queue.Full:
        print("\nWARNING: Audio buffer overflow — inference is lagging!")

# Consumer loop:
with sd.InputStream(samplerate=SAMPLE_RATE, channels=1, callback=callback,
                     blocksize=block_size, dtype="float32", device=device):
    buffer = np.zeros(0, dtype=np.float32)
    while True:
        chunk = audio_q.get()
        buffer = np.concatenate([buffer, chunk.flatten()])
        if len(buffer) >= block_size:
            clip = buffer[:block_size]
            buffer = buffer[block_size // 2:]  # 50% overlap sliding window
```

### Buffer Dynamics Analysis
*   `block_size` is set to $16,000$ samples ($1.0\text{ s}$).
*   `sd.InputStream` delivers chunks of $16,000$ samples once every $1.0\text{ s}$.
*   When a chunk arrives, the consumer slices `clip = buffer[:16000]` and retains `buffer[8000:]`.
*   **Observation:** Because the `if` statement executes once per queue item, the buffer retains 8,000 samples each second. For true continuous 500ms streaming without latency accumulation, `sd.InputStream` blocksize must equal the hop size (8,000 samples) or the consumer must loop `while len(buffer) >= block_size:`.
*   **Measured Desktop Processing Time:** Steady-state MFCC feature extraction + TFLite inference averages **4.91 ms** per window (max 7.93 ms) on host CPU, well below the 500 ms hop interval.
*   **Latency Definitions:**
    *   *Processing latency:* $4.91\text{ ms}$ (time to compute MFCC and infer on a ready buffer).
    *   *Detection latency:* Up to $500\text{ ms}$ (delay until the next sliding hop ingests the completed keyword).
